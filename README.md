# schedule-management

> 컴퓨팅 사고 기반 일정 관리 — 하루 일정을 실행 단위로 쪼개고 효율적인 순서로 배치해, 매일 아침 Slack으로 보고합니다.

커스텀 서버도, 직접 짠 코드도 없습니다. Claude Code의 스케줄(cron) 루틴이 매일 지정한 시각에 캘린더를 읽어 하루 계획을 만들고 Slack으로 보냅니다.

## 동작 방식

매일 아침, 루틴은 네 단계를 거칩니다.

1. **읽기** — Google Calendar에서 오늘 일정을 조회합니다.
2. **쪼개기** — 고정 일정과 유동 태스크를 판별하고, 유동 태스크를 실행 단위로 분해합니다.
3. **배치** — 정해둔 기준(`priorityRule`)에 따라 하루 순서를 정합니다.
4. **보고** — 완성된 하루 계획을 Slack으로 보냅니다.

### 리포트 예시

```
[오늘 하루 계획]

09:00-09:30 팀 주간 회의 (고정)
  1) 3분기 실적 데이터 정리 (45분)
  2) 보고서 초안 작성 (60분)

11:00-11:30 고객사 통화 (고정)
  3) PR #485 리뷰 (20분)
```

- **고정 일정** — 캘린더의 실제 시각을 그대로 표시합니다.
- **유동 태스크** — 순서와 예상 소요시간만 표시합니다.

## 일정 등록

같은 Slack 채널에 일정을 적으면 캘린더에 등록됩니다. **1시간마다 확인**하므로 적은 즉시는 아닙니다.

```
나:  내일 15시 치과
     └ ✅  등록했습니다
           치과 · 7월 31일(금) 15:00-16:00
```

- 적은 표현을 **그대로** 등록합니다. 쪼개지 않습니다 — 쪼개기는 다음 아침 리포트가 합니다.
- 시각을 안 적으면 종일 일정으로, 소요시간을 안 적으면 1시간으로 등록합니다.
- 날짜를 못 읽으면 등록하지 않고 스레드로 되묻습니다.
- 처리한 메시지에는 리액션이 붙습니다. 같은 일정이 두 번 등록되지 않게 하는 표시입니다.
- `[TASK]`를 붙여 적으면 다음 아침 리포트에서 유동 태스크로 쪼개집니다.

잘못 등록되면 캘린더에서 직접 고치면 됩니다.

## 시작하기

### 1. MCP 커넥터 연결

claude.ai에서 **Google Calendar**와 **Slack** 커넥터를 연결합니다. → https://claude.ai/customize/connectors

### 2. `config.json` 준비

`config.example.json`을 `config.json`으로 복사한 뒤 본인 값을 채웁니다. `config.json`은 `.gitignore`에 등록되어 있어 커밋되지 않습니다.

| 키 | 설명 |
|----|------|
| `calendarId` | 읽어올 캘린더 (보통 `"primary"`) |
| `slackChannel` | 리포트를 받을 채널 |
| `timezone` | 시간대 |
| `reportTime` / `reportDays` | 리포트 시각 / 요일 |
| `workingHours` | 태스크를 배치할 시간대. 이 밖의 시간은 비워둡니다 |
| `priorityRule` | 배치 기준. 자연어 문장으로 적습니다. 예: `"마감이 급한 일을 먼저 배치한다"` |
| `onOverflow` | 하루에 다 담기지 않는 태스크를 얼마나 강조할지. `"push"`(기본, 머리말만) / `"flag"`(구분선까지) |

### 3. 시험 실행

루틴을 등록하기 전에 가상 일정으로 한 번 돌려봅니다. Claude Code에서 이렇게 요청하면 됩니다.

```
test/run.md 대로 검증해줘
```

캘린더 대신 `test/golden-events.json`의 목 데이터를 읽어 판별·분해 결과와 gap 계산, 완성된 리포트를 보여줍니다. 스펙이 답을 주지 않는 상황을 만나면 임의로 정하지 않고 그 지점을 알려줍니다.

`priorityRule` 문장을 바꿔가며 돌려보고 순서가 원하는 대로 나오는지 확인한 뒤 다음 단계로 넘어가세요. 실제 캘린더를 읽지도, Slack으로 보내지도 않으니 몇 번이든 돌려도 됩니다.

### 4. 루틴 생성 요청

Claude Code에서 이 저장소를 열고 `/schedule` 스킬로 루틴 **두 개**를 만듭니다.

| 루틴 | 스펙 | 주기 |
|---|---|---|
| 리포트 | `docs/specs/decompose.md` + `docs/specs/arrange.md` | `reportTime`에 하루 한 번 |
| 등록 | `docs/specs/register.md` | 1시간마다 |

각각 해당 스펙과 `config.json`을 보여주며 "이 스펙대로 실행되는 스케줄 루틴을 만들어줘"라고 요청하면 됩니다. 등록 루틴만 캘린더 쓰기 권한이 필요하고, 리포트 루틴은 읽기만 합니다.

### 5. 매일 아침 리포트 수신

이후로는 `config.json`에 적어둔 시각마다 루틴이 알아서 실행되어 하루 계획을 Slack으로 보냅니다. 배치 결과가 마음에 들지 않으면 `priorityRule` 문장만 고치면 됩니다.
