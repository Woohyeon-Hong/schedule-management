# 배치(arrange) 스펙

## 목적
[decompose](./decompose.md)가 만든 항목들(`kind: fixed | task`)을 받아, 유동 태스크(`task`)를 고정 일정(`fixed`) 사이의 빈 시간에 배치하고 Slack 리포트로 만든다.

## 사용하는 config.json 필드
- `workingHours`: 하루의 배치 가능 구간 (예: `"09:00-18:00"`). 이 밖의 시간에는 태스크를 배치하지 않는다.
- `priorityRule`: 유동 태스크의 순서를 정하는 기준(자연어 문장). 이 문장을 배치 기준으로 그대로 따른다.
- `onOverflow`: `workingHours` 안에 다 못 들어가는 태스크를 얼마나 강조할지. `"push"`(기본, 머리말만) 또는 `"flag"`(구분선까지). 어느 값이든 태스크를 감추지는 않는다.
- `slackChannel`: 완성된 리포트를 보낼 채널.

## 배치 로직
1. `workingHours` 구간에서 고정 일정(`fixed`)의 `start`~`end`를 빼고, 남은 구간들을 빈 시간(gap)으로 잡는다.
   - 유동 태스크가 원본 캘린더에서 갖고 있던 시각은 **무시한다** — 그 시간도 gap이다.
   - 고정 일정이 `workingHours`를 벗어난 부분은 gap 계산에 영향을 주지 않는다. 완전히 밖에 있는 일정(예: 저녁 약속)도 리포트에는 실제 시각 그대로 표시한다.
   - **종일 일정**(시각이 없는 `fixed`)은 gap을 막지 않는다.
2. 유동 태스크(`task`)를 두 묶음으로 나눈다.
   - **우선 태스크** — `priorityRule`이 앞에 두라고 명확히 지목하는 것들. `priorityRule`이 "마감이 급한 일 먼저"라면 마감이 적힌 태스크들이 여기 해당한다.
   - **나머지** — `priorityRule`로는 우열이 가려지지 않는 것들.
3. 우선 태스크를 `priorityRule` 순서 그대로 앞 gap부터 넣는다. 현재 gap의 남은 시간에 안 들어가면 **순서를 바꾸지 않고** 다음 gap에서 다시 시도한다.
4. 그러고도 남은 빈 자리를 "나머지"로 채운다. 여기서는 순서보다 **빈 시간이 적게 남는 것**을 우선해 조합을 고른다.
5. 끝까지 넣지 못한 태스크는 리포트 맨 아래에 번호를 이어서 나열하고, **그 앞에 오늘 시간이 없다는 머리말을 반드시 붙인다.** 머리말 없이 나열하면 배치된 태스크와 구분되지 않아 할 수 있는 일로 읽힌다.
   - `onOverflow: "push"`: 머리말만 붙인다.
   - `onOverflow: "flag"`: 머리말을 구분선으로 감싸 더 눈에 띄게 한다.

순서에 관한 공통 규칙:
- 리포트의 순서 번호는 `priorityRule` 순서가 아니라 **최종 배치 순서**대로 매긴다.
- 한 이벤트를 쪼개서 나온 항목들끼리는 **분해 순서를 지킨다.** "데이터 정리 후 초안 작성"이면 정리가 먼저다. 4번의 빈 시간 최소화와 충돌하면 분해 순서가 이긴다 — 앞 항목을 건너뛰고 뒤 항목만 넣지 않는다.
- 그 외에 순서를 정할 근거가 없으면 원본 캘린더 시각이 이른 것을 먼저 둔다. 임의로 정하면 같은 일정에 매일 다른 리포트가 나온다.

## 출력 형태 (Slack 리포트)
- 고정 일정: `start`~`end` **실제 시각**을 그대로 표시한다.
- 유동 태스크: **순서 번호 + 예상 소요시간만** 표시한다. 구체적 시각은 적지 않는다.
- 종일 일정: 맨 위에 `(종일) 제목`으로 모아 표시한다. 시각이 없으므로 시간표에 끼워 넣지 않는다.
- 그날 이벤트가 하나도 없으면 제목 아래에 `오늘 일정 없음` 한 줄만 보낸다.

```
[오늘 하루 계획]

(종일) 3분기 보고서 제출 마감일

09:00-09:30 팀 주간 회의 (고정)

  1) 3분기 실적 데이터 정리 (45분)
  2) 보고서 초안 작성 (60분)

11:00-11:30 고객사 통화 (고정)

  3) PR #485 리뷰 (20분)
  4) 이메일 회신 (15분)
```

하루에 다 들어가지 않은 태스크는 맨 아래에 머리말과 함께 붙인다.

```
오늘 남은 시간에는 들어가지 않습니다

  5) 신규 기능 기획서 작성 (90분)
```

`onOverflow: "flag"`이면 같은 머리말을 구분선으로 감싼다.

```
──── 오늘 남은 시간에는 들어가지 않습니다 ────

  5) 신규 기능 기획서 작성 (90분)
```

완성된 리포트를 `slackChannel`로 보낸다.

## 금지
- 고정 일정의 시각 변경
- 유동 태스크에 시각을 지어내 표시하는 것
- 태스크를 리포트에서 누락시키는 것 — `onOverflow` 어느 값에서도 전부 표시한다
- 캘린더 쓰기 API 호출 (재배치·수정 포함), 다음날 일정 변경
